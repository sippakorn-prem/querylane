# Querylane v0.1b1

Local-first SQL client for macOS. No cloud. No subscription.

## What's included

- **Connections** — Save and manage PostgreSQL / MySQL connections locally
- **Query editor** — Syntax highlighting, schema autocomplete, auto-formatter, query history
- **Schema sidebar** — Browse databases, tables, and columns
- **Safety prompts** — Confirms before `DELETE`, `DROP`, `TRUNCATE`, and `UPDATE` without `WHERE`
- **Auto-updater** — Check for updates in Settings

## Install

1. Download `Querylane_0.1.0_universal.dmg`
2. Drag to Applications
3. Right-click → **Open** (required on first launch — app is unsigned)

## Known limitations

- macOS only
- PostgreSQL and MySQL only
- No in-grid editing or data export yet
